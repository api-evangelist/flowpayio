# Flowpay

> Flowpay is an embedded-lending fintech providing fast, flexible, non-purpose financing of up to EUR 100,000 to small and medium-sized businesses across the Czech Republic, Slovakia, and the Netherlands. Partners embed the full lending journey - onboarding, open-banking and sales-data ingestion, offer generation, and financing origination and repayment - via a REST partner API, hosted embed/linkout surfaces, and a JavaScript/React SDK. Auth is OAuth 2.0 client-credentials (Auth0); webhooks are HMAC-SHA256 signed. Techstars-backed.

## APIs

- [Flowpay Partner API](https://developers.flowpay.io/specifications/fully-embedded-api/): Fully Embedded (Native) lending flow - customers, open banking, offers, financings. Base URL https://api.flowpay.io (test https://api.test.flowpay.io), path prefix /partner-api/v1.
- [Flowpay Sales Transactions API](https://developers.flowpay.io/specifications/sales-transactions-api/): Partner-implemented GET /v1/sales endpoint supplying paginated merchant sales/order history for scoring.

## Authentication

- OAuth 2.0 client-credentials via Auth0. Token URL (prod) https://flowpay.eu.auth0.com/oauth/token, audience https://api.partner.flowpay.io. Present as Authorization: Bearer <token>.
- Sales Transactions API also accepts a static X-API-Key header.
- Credentials: CLIENT_ID, CLIENT_SECRET, PARTNER_CODE, WEBHOOK_SECRET.

## Webhooks

- Events: customer-scoring, financing-state (HTTPS POST).
- Signed with HMAC-SHA256 in x-flowpay-sig; x-flowpay-ts timestamp guards replay.
